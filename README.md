# 可可子人格管理 0.4.0

固定核心人格，自动积累群内表达、同 QQ 跨群相处记忆与事件时间线。适配现有 `astrbot_plugin_access_gate`，只处理 OneBot/NapCat 的 QQ 群聊。

## 启用

1. 将本目录放入 AstrBot 的 `data/plugins/`，保留现有独立白名单门禁和其他插件配置。
2. 在本插件配置中选择可可子实际使用的**原生人格 ID**。默认值为 `可可子`；若实际 ID 不同，必须重新选择。
3. 默认自动发现收到消息的 QQ 群，无需先填写群号。在管理页“设置与方向 → 选择学习的群”按群名或群号搜索，分别勾选“旁听学梗”和“互动记忆”，点击“保存设置”。新发现的群默认仅登记信息，两个学习开关关闭，全局梗也默认关闭。
4. 在“忽略的QQ号”加入菌菌等其他机器人账号。自身消息自动排除；OneBot 无可靠机器人标志时，其他机器人需通过此配置排除。
5. 选择后台学习模型，或留空跟随源群当前聊天模型。默认每日全部群最多 12 次 / 60000 tokens、每群最多 4 次 / 20000 tokens；失败和超时保守计预算。任一相关预算设为 0 即停用模型抽取，简单明确偏好仍可本地提取。
6. 重载插件，在插件详情中打开“人格管理”页面。全部 34 项配置都可在“设置与方向”编辑，与 AstrBot 原生配置共用一份数据，保存后用于后续处理，无需再次重载。
7. 按实际模型供应商的价格表填写北京时间低价时段，再填写进化方向。低价时段默认留空，不预设任何公司的折扣时段；空列表全部按常规价处理。

安装和启动不会改写原生人格。管理页面会读取并备份当前核心；“载入推荐核心”仅载入草稿，点击保存才更新该原生人格的 `system_prompt`，工具白名单、开场对话及其他人格不变。推荐底稿在 [persona_seed.txt](persona_seed.txt)，按已确认设定整理，保存前可编辑。

声明最低 AstrBot 版本为 4.24.0，使用临时 `TextPart`、人格管理、插件 Pages 与后台 LLM 接口；实现依据当前官方文档及源码，部署版本的完整兼容性仍需实际联调。运行时无新增第三方依赖。

## 触发与共存

- 门禁负责权限、开放时段、称呼、@ 和提及判断；本插件不复制触发分类器，不调用 `stop_event()` 或 `should_call_llm()`，不发送聊天消息。
- 群目录监听优先级为 10002，在现有门禁前仅登记群元数据；不读取聊天正文、不设置路由位、不调用模型。旁听正文采集仍为 9998，低于现有门禁的 10000/9999，只有活动门禁可见、群消息未被停止、实际人格匹配且勾选对应群时才采集。
- 互动依赖门禁在可信事件中写入的 `access_gate_original_text`，实际进入主聊天请求并发送回复后才记录。单独匹配指令或其他插件的 LLM 请求不视为相处互动。
- 复核会话插件集和会话级禁用状态；其他插件设置的显式 `provider_request` 不注入。只确认普通主聊天的已发送结果，或有已发送内容的流式完成结果；错误与未完成输出不记作相处成功。
- 自身标记的临时上下文可重复替换，其他插件的上下文、原始问题、图片、工具列表、系统提示和对话历史不改动。
- **私聊始终跳过**：不采集、不检索、不注入、不调用学习模型，也不会中断 RTLink 绑定等现有私聊指令。
- 本插件不新增聊天口令或 LLM 工具。管理操作集中在登录后的 AstrBot Dashboard，避免在群里展示整份人物档案。
- 不会接管 RTLink、六爻、五行、紫微的计算、输出、额度和权限。已有专业插件可自行发送结果。

默认 Agent 的触发取决于门禁处理后的 `is_at_or_wake_command` 和 `call_llm`；框架的普通监听器可能设置 `is_wake`，不能仅靠该标记判断人与可可子的互动。本插件只读上述路由状态。

“私聊不消耗 token”指本插件对私聊的新增调用为零。本插件不会修改现有门禁：如果门禁配置另外放行了私聊 AI，主聊天或其他插件仍可能调用模型。保持全机器人私聊不聊天，需要现有门禁继续禁止私聊 AI，同时保留需要的私聊命令入口。

当前门禁适配按工作区 Access Gate 1.4.0 的实际处理函数验证。后台权限复核使用它现有的只读配置方法；无法确认门禁接口、会话授权或人格时跳过学习，不另外启动触发判断。框架确认发送完成不等于 QQ 端已送达。

## 自动群目录与群开关

机器人收到群消息后，目录记录群名、群号、平台连接、机器人 QQ、首次/最近发现时间，以及接口可用时的成员总数。这里只保存群元数据，不保存群成员名单、发送者或聊天正文。群目录与人格选择、学习暂停和门禁放行无关；关闭本插件总开关或平台/会话未加载本插件时不再发现新群。框架在插件运行前就过滤的消息不可见，因此目录不等于机器人加入的完整群名单，也不会主动拉取历史聊天。

群名优先读取真实事件元数据，并在后台调用 OneBot `get_group_info` 补全与刷新；不调用 `get_group_member_list`，不调用模型。成功缓存 24 小时，失败后至少 1 小时才在后续群消息中重试；单次超时 5 秒，并发最多 8 个查询，不阻塞门禁等待网络。最近发现时间按约一分钟粒度写入。群名未知时显示“群名待获取”，已有名称查询失败时保留缓存。

- “旁听学梗”控制该群的表达采集、后台抽取和表达注入。
- “互动记忆”控制该群的个人记忆采集、后台抽取和召回；还需打开全局人物记忆开关。同 QQ 的身份和时间线继续在启用的群之间共享。全局梗开关不开放个人记忆。
- 旁听与互动开关独立；勾选只修改草稿，保存后生效。关闭后保留历史数据，不补收关闭期间的正文；在途旧学习结果作废。修改这里的开关不会放行原有白名单门禁或唤醒规则。

升级时，已有来源记录中的群会补入目录，缺少群名的等待下一条真实群消息查询。原有旁听白名单继续有效；**互动记忆改为明确选择群**，旧记忆不删除，在列表勾选“互动记忆”后可继续使用。群开关与原生 `observation_groups`、`memory_groups` 配置共用一份数据，高级群号输入默认折叠。旧版 `memory_disabled_groups` 排除设置仍有效，手动开启该群互动记忆时会解除该群的排除。

开关按“平台连接 + 群号”保存。同一群出现在多个连接时分别展示；关闭其中一个连接会把旧的通用群号规则收窄为其余已发现连接，避免同时关闭其他连接。不在列表中的高级配置条目会保留。

## 全局梗与群标签

每个群卡片新增“群标签”和“允许使用全局梗”。标签用于描述群的性格、话题和能力领域，例如 `太鼓达人、闲聊、技术交流`；最多12个，每个最多24字。直接在群卡片填写，无需输入群号，保存设置后生效。标签不会改变人格身份、权限或真实工具能力。

- 全局梗开关默认关闭，旧群、新群均不自动开启。关闭时保持原有本群表达逻辑；本群表达仍由旁听开关控制。
- 当前人格下所有**已启用**表达自动参与全局匹配，包括升级前已经学会的表达；候选、停用和遗忘的表达不参与，不把多个群的证据合并以绕过启用门槛。
- 全局开关与采集开关独立。可以只使用全局梗而不旁听、不记录人物记忆；仍须通过现有门禁并使用目标人格。没有群标签时不使用外群表达。
- 第一版使用本地关键词规则：目标群至少一个标签出现在梗的含义或适用语境中，并且不命中避用语境，随后再检查当前对话语境。英文标签忽略大小写并检查词边界，不做额外模型语义分类；同义说法未命中时会保守跳过。建议填写明确的话题和性格关键词，避免用长段指令作为标签。
- 优先选择本群表达，再补充匹配的外群表达；相同文本去重，每轮合计最多2条并限制近期重复。专业/求助关键词抑制及动态上下文长度上限继续生效。读取和匹配不额外调用模型，注入的文本仍计入主聊天输入。
- 全局库引用原表达，没有复制出另一份数据。停用、遗忘或回滚原表达会同步影响其全局可用性；其他群独立学会的同文表达仍有自己的生命周期。关闭某源群旁听只停止该群采集及本地使用，已有表达仍可供其他已开启全局梗的群匹配；要全面撤回某条表达，请在“群表达”中停用它。
- 开关和标签按平台连接及群号保存，支持不同连接分别配置。原生高级字段是 `global_style_groups` 和 `group_tags`，与面板共用配置、版本冲突及保存校验机制。修改标签或关闭全局开关后，后续请求立即使用新配置。

## 两条学习路径

**旁听**：仅白名单群，读取顶层文本，不展开引用、转发或附件。样本只可生成群表达候选，不能生成个人档案。候选须有真实文本证据，经过规则/身份/敏感信息检查；同一表达至少来自 3 人、2 个北京时间日期、5 次独立出现，同一用户同小时只计一次。每群每天最多自动启用 2 条，最多保持 20 条活跃表达。门槛为首版固定值。

**相处记忆**：与旁听白名单独立，仅在选择了“互动记忆”、门禁实际放行且使用目标人格的群生效；“不记录和使用人物记忆的群”可单独排除。已回复的原消息进入个人记忆队列，`叫我阿青`、`回复简短一点`、明确当前练习目标等有限模板先用本地规则处理；其他内容后台抽取。模型只能提交有原文证据的候选，不能指定另一人的 QQ 或修改核心人格。

模型输出的事实内容使用已核验的原文片段，不采信扩写。引用中的“我”、第三方说法、模型自己的回答不作为本人的新事实。含多个阶段且不能可靠拆分的陈述会保守跳过；这是一版有限抽取器，不能保证理解任意省略、反讽和复杂指代。

### 跨群人物与群内表达

- 人物：`目标人格 + 可信QQ号`。称呼、偏好、练习目标和熟悉程度跨群共享；昵称只是展示信息，不凭自称合并账号。
- 表达：`人格 + 平台实例 + 机器人QQ + 群号`。默认群 A 的梗不注入群 B；目标群开启全局梗并通过标签及对话语境匹配后可以复用。
- 熟悉程度按跨群去重的有效互动天数划分初识/熟悉/熟络/长期熟络（3/10/30 天），只影响表达，不改变办事质量和权限。
- 每轮只读取当前人的小量认知及相关事件。来源群留在管理视图，普通聊天上下文不附来源群或原始 QQ。
- 当前实现默认把明确个人偏好跨群共享；专门限定某群的复杂偏好若不能可靠抽取会跳过。实际结果需要在管理页面核查和纠正。

## 时间线

区分原消息发送时间、记录时间、事件发生区间及状态有效时间。全部时间以 UTC 秒保存，解析和展示采用北京时间，不依赖服务器时区。

支持今天、昨天、前天、明天、上/下周及星期、周末、上/下月、明确日期与常见时刻。相对时间锚定原消息，不按后台处理时间重新解释。未知、含糊或非法日期保留未知；时间范围结束为不包含该时刻的边界。

例如 20 日说在练幽玄，28 日说改练万戈，29 日才处理到 20 日的旧消息，当前目标仍为万戈。计划、进行中、完成、取消分开记录，日期到了不自动完成。当前目标超过 30 天会在注入时标注需要确认。

当前练习与未来计划分别保留；去年、前年等按原消息解析。本周、本月等包含原消息时刻的状态按消息先后更新，不按周一或月初抢占顺序。含糊、非法或无法定位的历史时间只保留在线索中，不据此改写当前认知。合法日期不会误当电话号码过滤。跨群追问“之前在练什么”可召回旧目标及偏好，避免只查经历类记录。

明确纠错可在管理页定向修改正文、时间和状态；旧记录标为已纠正，历史可追溯，普通回复不再使用被纠正事件。未另填时间时保留原事件时间，修改历史记录不会让它抢占当前状态。模型不自行猜测纠错目标 ID。首版没有把任意自然语言的计划、取消和完成自动合并为同一个任务的能力，会保留有来源的阶段记录供理解和管理。

纠错后原证据只供审计，不再送入自动学习，避免下一批换个主题重新学回旧说法。时间字段未改或留空都会保留原锚点；更改时间时建议使用明确日期。0.1.0 数据库会自动补充时间表达字段，保留既有记录。

## 价格时段与进化方向

这里的高低峰由**配置的模型价格时段**决定，不按群消息活跃度判断。支持多个北京时间时间窗、跨午夜，例如 `23:00-07:00` 仅为格式示例，并非 DeepSeek 当前价格声明。时间为 `00:00`～`23:59`，起点包含、终点不包含；起止不能相同。低价时段留空表示无低价时段，允许后台学习时间窗留空则表示全天允许。

| 配置 | 常规价默认 | 低价默认 |
| --- | --- | --- |
| 同群同 QQ 互动积累门槛 | 3 条 | 1 条 |
| 群旁听积累门槛 | 20 条 | 5 条 |
| 同类批次学习间隔 | 30 分钟 | 5 分钟 |

常规价时积攒少量互动也能更新，低价时更及时处理积累内容。小批内容等待超过 6 小时后可放宽条数门槛，但不会绕过允许学习时间窗、冷却、权限、来源验证和预算。此时间是允许小批处理的门槛，不保证一定在 6 小时内更新。关闭分时学习后，互动恢复 1 条门槛，旁听与冷却使用常规设置。

“进化方向提示词”最多 4000 字，用于指导后台学习的关注点、表达取舍和应减少的习惯，例如：

> 闲聊简短自然，减少复读和固定口癖；关注群友太鼓练习目标与后续进展。专业问题重视事实依据和当前工具结果，不学会编造能力或结论。

页面可载入参考方向到草稿，保存后才生效。方向不会自动改写核心人格，也不会直接注入主聊天；学习内容仍须有真实样本证据，不能靠方向提示新增事实、工具能力或权限。修改方向和学习设置会使正在处理的旧结果失效；已经发出的模型请求仍可能产生用量。

## 成本、保留期与后台生命周期

- 普通回复只执行本地数据库读取，不新增前台分类模型调用。
- 每轮动态上下文默认最多 1800 字符，按完整条目裁减。专业/严肃请求降低梗的注入，短期内避免重复同一表达。
- 后台每 30 秒检查一次，每轮最多调用一次模型；同一旁听群/同群同人的互动按上表分别冷却。每批默认最多 30 条、原文总计最多 12000 字符，可在面板调整。
- 提供商调用使用独立提示、空历史、无工具；请求输出上限默认 1200 tokens，可设 256～4096，实际参数执行与计费仍取决于提供商。插件另限制返回文本及候选数。
- 调用次数与 token 预算按北京时间日持久化，重载不清零。发出前原子预留全局与群额度，成功后按供应商报告结算；未获得完整用量、超时或取消则保守占用。确认没有调用模型的预留会释放；进程中断后的未知预留保留，不冒充零消耗。
- 预估采用请求 UTF-8 字节数、消息包装余量和输出上限，因此会比常用 tokenizer 保守；它不是供应商账单或任何模型的绝对上界。单批预估超出剩余额度时不发起请求，页面显示原因；可调小单批长度或调整预算。提供商额外内容或不遵守输出上限仍可能造成实际用量高于预留。
- 学习总览分别显示已报告输入/输出、估算占用、在途预留、今日调用、近 7 天趋势、各群今日用量和最近学习的采纳数。旧版仅有调用次数、没有 token 数据的记录标为未知；切换目标人格不清空全部群的总预算。
- 这里只统计本插件后台学习。动态上下文会占用主聊天输入，主聊天与专业插件的完整用量仍交给已有统计插件，不重复计算为后台学习。
- 每次调用前及结果入库前复核源群门禁、插件启用、当前人格和学习配置；撤回后不新增调用，已发出的调用可能仍计费，但旧结果不会入库。全局与群预算一起原子预留，并发调度不重复提交同批；被禁用群的大量旧样本不会堵住后续群。
- 原文过滤后为空，或旁听有效样本不足门槛时不调用模型。
- 暂停/关闭学习停止新增采集与抽取，原文到期清理继续运行，已有有效记忆仍可使用。
- 原文默认旁听 48 小时、互动 7 天。已采纳的短记忆、表达、来源标识与互动日期单独保留，支持显式遗忘。请勿把原文保留期理解为全部派生数据的保留期。
- 移除旁听白名单后停止该群新采集、抽取和表达注入；已有记录保留供管理。停止插件时取消并等待后台任务。

## 管理页面与恢复

所有 API 需 Dashboard 登录，且核对目标人格、记录和群作用域。页面通过官方 `AstrBotPluginPage` bridge 访问，不使用外部 CDN 或单独监听端口。

- 核心：编辑、查看版本、恢复旧版本；仅人工操作修改。
- 人物：按 QQ 查看当前认知及时间线，纠正单条、遗忘单条或该 QQ 的全部记忆。
- 群表达：查看候选/已启用表达、来源编号，禁用、回滚该群表达版本。
- 学习总览：暂停/恢复，查看用量、预算、样本门槛、当前价格时段、等待原因和近期学习结果；运行状态保留最近上下文引用编号。
- 设置与方向：先按群名搜索并勾选学习群，再管理全部 34 项分组设置，支持人格/模型选择、范围、预算、分时积累、方向和保留期。后端严格校验数值、时间窗及组合约束；不提供私聊启用项。

刷新状态会保留未保存的人设与配置草稿。其他页面改动配置后会提示版本冲突，需重载并核对草稿，避免静默覆盖；保存失败不显示成功。自定义页面使用 AstrBot 的原生配置保存接口，不另存第二套配置或 API 密钥。

遗忘会清空相关正文/派生内容、撤销相关表达并保留非正文重放标记；已进入处理中的旧结果因版本变化而失效。暂停切换、纠错和表达回滚也使旧后台任务失效。回滚表达不会倒退个人时间线，已遗忘内容不会被版本恢复复活。

备份前先暂停/停止插件；数据位于 `data/plugin_data/astrbot_plugin_persona_manager/persona.sqlite3`。SQLite 使用 WAL，运行时不能仅复制主数据库文件充当一致备份。恢复外部旧备份可能恢复备份时的数据，不属于应用内回滚保证。
